# version2.7

## Summary

v2.7 实现两个豆瓣已看整理前功能：

- 读取 / 书签导入时区分电影和剧集，准备页可以按条目类型筛选。
- 读取完成后可在预览列表里点 `×` 手动移除一眼不想排的条目。

本次更新不修改 Supabase schema，仍然使用 `imported_movie_lists.items` 的 JSONB 结构保存扩展字段。

## 实施计划

- 豆瓣已看导入 entry 新增 `media_type` 字段，内部值为 `movie`、`series` 或 `unknown`。
- 服务器一键读取和浏览器书签导入分别读取豆瓣 `type=movie` 与 `type=tv`，打标后合并去重。
- 旧导入 ID 没有类型字段时归为未识别类型，不阻止继续整理。
- 准备页筛选顺序固定为：类型 -> 评分 -> 标记年份 -> 手动移除。
- 预览列表升级为可编辑候选表，每个条目右侧提供 `×` 按钮。
- 增加“已手动移除 X 部”和“恢复全部”操作。
- 手动移除只影响本次整理，不写回云端导入片单 ID。
- “当前将整理 X 部”和预计取舍次数基于最终候选列表计算；少于 2 个条目时阻止开始整理。

## 功能细节

### 电影 / 剧集类型筛选

- `import_store.py` 增加 `clean_media_type`，统一清洗 `movie`、`tv`、`series`、中文“电影 / 剧集”等输入。
- `merged_douban_ranker_v3.py` 的豆瓣服务器读取会按电影和剧集分别请求，并按标记日期重新排序。
- 浏览器书签工具同样分类型读取，保存时写入 `subject_id` 和 `media_type`，便于合并去重与后续筛选。
- 准备页新增“按条目类型筛选”，提供全部类型、只看电影、只看剧集、清空类型和包含未识别类型。

### 片单预编辑

- 读取或导入成功后，预览列表基于类型、评分、年份筛选结果展示。
- 每个候选条目右侧有 `×` 按钮，点击后该条目仅从本次排序候选里移除。
- 可通过“恢复全部”清空本次手动移除记录。
- 开始整理时使用最终候选列表，因此已手动移除的条目不会进入 1v1 取舍流程。

## 数据兼容说明

- 不需要数据库迁移。
- 新导入会在 JSONB entry 中保存 `media_type`。
- 旧导入没有类型字段时仍可读取和整理；界面会显示为未识别类型。
- 想让旧导入获得电影 / 剧集筛选能力，需要重新读取豆瓣 ID 或重新执行浏览器书签导入。
